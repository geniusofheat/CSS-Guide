css_guide_engine.js — Full Element & Class Reference

TIER 1 — Toggle Navigation List

Functions: build_toggle_list  |  toggle_item  |  on_version_click

  • <ul> — .topic-list — root list wrapper; contains all version group items
  • <li> — .version-group .content-block — list item for a CSS version; two classes on the same element
  • <div> — .topic-trigger — clickable row wrapper holding the chevron and heading; used at both level 1 and level 2
  • <em> — .chevron — expand/collapse arrow; triggers toggle_item() on click
  • <h4> — no class — version or topic name text; triggers on_version_click() or on_topic_click() on click
  • <ul> — .topic-group-list .hidden — nested list under a version; expands to show topic groups; hidden on load
  • <li> — .topic-group — list item for a topic group inside a version
  • <ul> — .topic-property-list .hidden — nested list under a topic; expands to show properties; hidden on load
  • <li> — .property-item — list item for an individual CSS property; triggers on_property_click() on click

TIER 2 — Version & Topic Detail Card

Functions: render_version_detail  |  render_topic_detail  |  toggle_expand  |  on_topic_click

  • <div> — .card — main content wrapper for the detail panel
  • <h3> — no class — version or topic name displayed as the card heading
  • <p> — no class — release date or CSS version line; contains a <strong> label and plain text value
  • <strong> — no class — bold label text inside the <p> row (e.g. "Released :" or "CSS Version :")
  • <hr> — no class — horizontal divider between the header info and the expand sections
  • <ol> — .expand-list — ordered list holding all expandable sections (Lessons, Definition, What It Introduced, Note, Tip)
  • <li> — no class — each row inside .expand-list; one per expandable section
  • <div> — .expand-title — clickable heading for each expand section; .expanded added when open
  • <div> — .expand-body .hidden — collapsible content area under each expand title; hidden on load
  • <p> — no class — text content inside .expand-body (definition, note, tip, what it introduced)
  • <ul> — .topic-property-list — list of lessons inside the Lessons expand section
  • <li> — .property-item — each clickable lesson name row inside .topic-property-list

TIER 3 — Property Detail Card

Functions: render_lesson_detail  |  on_property_click

  • <div> — .card — main content wrapper for the property detail panel
  • <h3> — no class — property name heading at top of card (e.g. "Property Name : color")
  • <h4> — no class — section label headings throughout the card (Reference, Property Info, Default Value, Syntax, Tip, Note, Values, Examples, Browser Support)
  • <p> — no class — definition text, default value text, default value description, applies-to text
  • <a> — no class — W3Schools reference link; opens in new tab
  • <hr> — no class — horizontal divider below the reference link
  • <ul> — no class — property info list (Inherited, Animatable, Applies To); also used for browser support list
  • <li> — no class — each row inside the property info list and browser support list
  • <strong> — no class — bold label inside each info list row (e.g. "Inherited:", "Chrome:")
  • <pre> — .code-block — preformatted code block; used for syntax display and code examples
  • <p> — .syntax-example — inline syntax or units note displayed under a value description
  • <ol> — no class — ordered list for the Values section and the Examples section
  • <li> — no class — each value item or example item inside those ordered lists
  • <h5> — no class — value name or additional value name inside a values list item
  • <ul> — .additional-values-list — nested list of extra sub-values beneath a main value item
  • <li> — no class — each item inside .additional-values-list; contains h5, p, and optional .syntax-example
